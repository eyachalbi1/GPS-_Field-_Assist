============================================================
COMMANDES PRINCIPALES - GPS Field Assist Service
============================================================

GESTION DU SERVICE (Clic droit → Exécuter en tant qu'administrateur):
----------------------------------------------------------------------

1. DEMARRER le service:
   → start_service.bat

2. ARRETER le service:
   → stop_service.bat

3. VERIFIER l'état:
   → check_service.bat

4. REDEMARRER le service:
   → Arrêter puis démarrer


COMMANDES MANUELLES (dans CMD en administrateur):
----------------------------------------------------------------------

Démarrer:    net start GPSFieldAssist
Arrêter:     net stop GPSFieldAssist
Statut:      sc query GPSFieldAssist
Redémarrer:  net stop GPSFieldAssist && net start GPSFieldAssist


VERIFICATION:
----------------------------------------------------------------------

1. Ouvrir navigateur: http://localhost:8000
2. Depuis téléphone: http://192.168.0.2:8000


GESTION DES UTILISATEURS:
----------------------------------------------------------------------

Ajouter utilisateur:     python add_user.py
Lister utilisateurs:     python list_users.py
Gérer utilisateurs:      python manage_users.py


LOGS ET DÉPANNAGE:
----------------------------------------------------------------------

Voir les logs du service dans:
C:\Users\Asus\Desktop\gps-field-assist_ver_2_1_2\backend\logs\


IMPORTANT:
----------------------------------------------------------------------
- Le service démarre automatiquement au démarrage de Windows
- Pas besoin de shell ouvert
- Fonctionne 24h/24
- Connexion WiFi uniquement (pas de câble)
